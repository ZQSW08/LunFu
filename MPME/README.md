## 原文方法的实现定义

深度研究报告可作为背景材料，但实现以论文第 2-4 节、式 (1)-(26) 和 Fig. 4
伪代码为准。原方法不是简单地把逐像素相位差乘以波长，而是以下流程：

1. 对参考帧和运动帧建立二倍降采样的高斯金字塔。
2. 在最粗层从零位移开始；在每个更细层把上一层位移放大 2 倍作为初值。
3. 用当前初值扭曲运动帧，使当前层只剩小幅残差运动。
4. 分别使用 `theta = 0, 45, 90, 135` 度的复数二维 Gabor 滤波器计算响应
   `q = A exp(i*phi)`。
5. 用相位恒常性建立每个方向的约束：

   `c_x*u + c_y*v + c_t = 0`

   其中 `c_x`、`c_y` 是相邻帧平均相位的空间梯度，`c_t` 是帧间相位差。
6. 用式 (7) 的幅值置信度和式 (8) 的方向一致性掩膜筛除弱响应、相位奇点和
   反方向频率。
7. 在局部窗口内累计四个方向的约束，形成论文式 (17)-(23) 的 7x7 对称矩阵
   `Q`；求解 6 参数局部仿射模型。条件良好时解线性方程，病态时用 SVD。
8. 取局部仿射模型在窗口中心的平移量作为残差位移，与层间初值相加；重复到
   最细层。

位移约定固定为：`d(x)` 把参考帧坐标映射到运动帧，即
`I_ref(x) ~= I_mov(x + d(x))`。扭曲时使用逆采样，避免正向散射产生空洞。

## 必须先冻结的歧义与处理原则

论文存在若干会直接影响结果的缺失或不一致。实现时不悄悄猜测，而是在首次
baseline 配置中明确记录采用值。

| 问题 | 原文情况 | baseline 处理 |
| --- | --- | --- |
| 式 (5) 的量纲 | 论文写成 `delta_x=(2*pi/lambda)*delta_phi`，与式 (1) 的波数关系相反 | M-PME 主流程按相位约束方程求解，不依赖式 (5)；单方向 PME 对照使用物理一致的 `lambda/(2*pi)`，并在结果中标注论文疑似排版错误 |
| 相位差计算 | 论文写 `phi_2-phi_1`，未说明数值实现 | 使用 `angle(q_2*conj(q_1))` 得到稳定的主值相位差；多尺度负责保证残差不跨越 `pi` |
| 图像强度尺度 | 深研报告建议归一化到 `[0,1]`，但论文阈值 25 随响应幅值缩放 | 保留 `double` 的 `[0,255]` 强度用于论文阈值；若输入归一化，阈值必须同比例重标定，不能直接沿用 25 |
| 式 (8) 的 `n` | 方向向量定义不完整，且式 (7)/(8) 都写作 `C` | 将式 (8) 作为方向二值掩膜乘到式 (7) 的幅值置信度上；`n` 取 Gabor 正频率方向 |
| 局部窗口 `w` | 尺寸和加权核未给出 | 首次实现采用固定奇数方窗和均匀权重；只用一个小规模平移样例选择能使矩阵可解的最小窗口，不做大范围调参 |
| 相位梯度差分 | 未给出算子与边界方式 | 中心差分，边界采用对称延拓 |
| 局部仿射坐标 | 式 (16) 使用图像绝对坐标，可能导致病态；伪代码未说明窗口中心 | 窗口内坐标相对中心化，`a3/a6` 直接表示中心残差位移；SVD 作为论文明确给出的病态回退 |
| 扭曲插值和边界 | 未说明 | 双线性插值；越界点不进入约束拟合 |
| 参考帧策略 | 理论描述相邻帧，旋转实测又称静止图像为参考 | baseline 先实现帧对接口；序列入口显式选择 `adjacent` 或 `fixed-reference`，论文各实验按原描述设置 |
| 平移方向 | 第 2 节称 `theta=0` 提取 x，塔架段又称 `theta=0` 提取 y | 以 Gabor 核和坐标定义的数值响应为准，用已知 x/y 平移各做一次方向校准 |
| 评价数字 | 摘要、Fig. 12、结论数字不完全一致 | 旋转仿真以 Fig. 12 的 `MAE<0.4 px`、`STD<0.04 px`、`MaxE<0.7 px` 为论文目标，另报告实际计算值 |

论文还没有给出高斯面 `B, s, xi, omega_n` 的具体数值、旋转叶片原图、1975 个
评价点的选点规则、局部窗口尺寸、真实视频和传感器原始数据。这些缺失项意味着：

- Fig. 2/Fig. 6 可先做“方程与趋势复现”，不能承诺像素级重画原图；
- 旋转仿真先用自生成的带自然纹理叶片图验证已知仿射真值；得到论文原图后再做
  严格图像复刻；
- 两个真实实验暂只能实现数据入口和处理流程，不能在没有原始数据时宣称复现了
  Fig. 14 或 Fig. 19-20。

## 分阶段执行与验收

### 阶段 1：传统 PME 的测量范围

生成可解析的二维高斯面序列，覆盖小位移和超过半波长的大位移。先只实现单层
Gabor 响应、相位约束和全局/局部平移求解。

最低验证只使用一个静止样例和一个已知小平移样例。通过条件：符号和 x/y 方向
正确，小平移误差小于 0.1 px；随后运行 `k=1..4` 序列，应复现论文 Fig. 2 中
PME 在大位移区间发生包裹、在衰减后重新恢复的趋势。

### 阶段 2：M-PME 粗到细平移 baseline（首个里程碑）

加入高斯金字塔、位移上采样、运动帧扭曲和逐层残差累加，复现 Fig. 6 的核心
结论。通过条件：

- `k=1..4` 四个序列均能恢复完整衰减振动，不出现 PME 的周期性折返；
- 静止区域无系统漂移；
- 层间位移满足 `v_l = 2*v_(l+1) + a_l`；
- 误差曲线与运动幅值没有明显同步的包裹尖峰。

达到以上条件即形成 `baseline-v1` 候选，不追加无关的测试矩阵。

### 阶段 3：二维局部仿射与旋转仿真

构造 0:10:180 度的 19 帧旋转序列，使用四方向 Gabor、局部 6 参数仿射拟合和
4 层金字塔。先在程序生成的纹理目标上验证，再等待论文原始叶片图。

验收分两层：算法验收要求位移方向、旋转中心和空间分布正确，且高置信点 MAE
达到亚像素；论文目标参考 Fig. 12 的 0.4/0.04/0.7 px 阈值。若自生成纹理与论文
图差异较大，只报告算法验收，不把未达到/超过论文数字解释为论文复刻结果。

### 阶段 4：真实塔架与旋转叶片（代理已验证，原始数据待补）

真实入口中塔架使用 60 fps、3 层、`lambda=60`；旋转叶片使用 20 fps、4 层、
`lambda=30`、四方向与 `C>25`。同规格合成代理已经跑通。原始视频、ROI、轮毂
中心和传感器文件到位后，需在 `scripts/run_real_data.m` 中填写路径并正式复验。


不会改动视觉处理算法。当前 CSV 没有独立时间列，因此按 `laserFs=100` Hz 的样本序号建轴。

1. `config.roi` 为空时，程序显示首帧；拖动矩形后双击矩形内部确认。平移目标不必
   覆盖完整运动路径，只需在初始目标上包含至少 5 个稳定角点。细长竖边只对 x 位移
   有可靠约束，需设置 `primaryAxis='x'`；风扇则应框完整轮毂与尽可能多的叶片；
2. ROI 坐标会打印并保存到 MAT，后续可直接回填 `[x y width height]` 跳过框选；
3. `motionModel='rotation'` 时会依次要求点击轮毂中心和测点；也可预填 0-based 坐标；
4. 平移模式的动态 ROI 使用两遍处理：第一遍取得原始 KLT 轨迹并零相位低通，只让
   ROI 跟随低频大运动；第二遍重新裁剪，把微振动留给 M-PME。固定机位风扇默认不让
   ROI 追逐旋转叶片；只有轮毂整体也平移时才把 `followHubTranslation` 改为 `true`；
5. `config.output.clearPreviousResults=true` 时，每次运行会先安全清理该具体输出子目录，
   工程根目录、`outputs` 根目录和 `experiments` 根目录不会被清理。

### M-PME 合成、KLT 候选与大小运动分离

平移模式中所谓“M-PME 合成”不是把两条频谱相加，而是按同一坐标系将动态 ROI 的
低频粗位移与稳定裁剪内的相位残差相加：

`总位移 = 动态 ROI 粗位移 + M-PME 亚像素残差`。

KLT 曲线来自第一遍视频中的特征点轨迹。程序对有效特征点位移取鲁棒中值，形成原始
目标轨迹；再减去低通的大运动轨迹，得到用于交叉核验的 KLT 微动候选。它不参与
M-PME 相位求解，也不是第二份 M-PME 结果。新增的一维边缘相关曲线同样是独立验证器，
用于发现 KLT 身份漂移或相位跨周错误。

带通滤波只负责在已获得的位移中观察指定物理频段，不是大小运动分离的唯一关键。
真正的分离链路是“模板校验的目标跟踪 → 低通粗运动 → 二遍动态裁剪 → M-PME 残差 →
多估计器一致性判断”。`microVibration.bandHz` 控制显示/波形带通，
`frequencySearchBandHz` 控制主频搜索范围；已知结构频带时应据采样率、结构模态或 LDV
设置窄范围，不能用一个宽带滤波器自动区分所有大运动伪频与真实微振动。

当固定首帧参考下的相位残差跳变量超过 `phaseJumpFraction*lambda` 时，
`translation.referenceMode='auto'` 会改用相邻帧参考重新计算，避免约一个 Gabor 波长的
相位分支折叠。KLT 重检测后还会周期性与首帧边缘模板核对，以减少“点数仍足够、实际已
跟到背景”的静默漂移。输出的 `micro_result_reliable` 由 M-PME、KLT 和一维边缘相关的
主频与波形一致性共同给出；不可靠结果不会因为经过带通就被当作可信测量。

### 高速周期旋转体

高速风扇默认使用 `config.rotation.method='angular-harmonic'`。程序在轮毂周围的环带做
极坐标采样，提取与叶片数相同阶次的角向复谐波，由谐波相位恢复轴角，再除以叶片数。
因此它跟踪的是整圈周期纹理，而不是要求某一个叶尖在运动模糊下始终可见。原来的
KLT/切向光流/M-PME 混合方法仍可通过 `method='mpme'` 用于低速、非周期转子。

必须正确设置 `bladeCount`、视频真实帧率、轮毂中心和包含大部分叶片的 ROI。N 叶片的
单帧无歧义角增量约为 `180/N` 度，超过后仍可能发生转速混叠；输出中的
`maximum_unambiguous_rpm` 和 `alias_risk` 用于提示这一限制。测点仅用于轨迹可视化，
角度和转速不再依赖这些点是否能被 KLT 连续追踪。

### 动态 ROI 跟踪器选择

真实视频入口的 `config.tracker.type` 支持四种值：

| 值 | 作用 | 尺度框 | 适用情况 |
|---|---|---|---|
| `klt` | 当前项目的特征点/模板校验跟踪 | 固定 | 纹理充足、尺度基本不变，速度优先 |
| `fdsst` | 原版 DSST/fDSST | 支持 | 需要经典尺度滤波基线 |
| `fdsst_improved` | 用户提供的置信度门控和预处理版 fDSST | 支持 | 平移、尺度变化、低照度，默认推荐先试 |
| `eco_improved` | 用户提供的 ECO-HC 工程包装 | 支持 | 遮挡、外观变化较明显，速度较慢 |

四种方法都统一输出 `N×4` 的 `[x,y,width,height]`。其中 fDSST/ECO 的框宽高会随
尺度估计变化；为了不改变 M-PME 所需的固定三维帧数组，后端分析帧使用跟踪中心的
低频轨迹和初始尺寸进行固定尺寸裁剪，尺度变化仍完整保存在 `roiTrajectory`、
`tracking.scaleTrajectory` 和跟踪视频中。这样可以分别观察“跟踪框是否跟上尺度”和
“M-PME 残差是否稳定”，不把跟踪器的尺度估计混入相位位移量。

代码入口示例：

```matlab
config.tracker.type = 'fdsst_improved';
% 也可改为：'klt'、'fdsst'、'eco_improved'
```

`fdsst` 使用 `third_party/fdsst_original/` 中的最小适配副本；改进 fDSST 和 ECO
默认从用户提供的外部目录加载，不复制整套 ECO 源码。ECO 原项目带 GPL-3.0 许可，
若向工程外发布二进制或修改版，必须同时遵守其许可证要求。ECO 还会先把视频帧写入
本地缓存，正式长视频运行时间和磁盘占用都会高于 fDSST。

### 关于“大运动非线性”与相位非线性

二者不能混为一谈：时间轨迹非正弦、有加速度或包含高阶谐波，并不会破坏局部
相位恒常性；只要每个金字塔层的残差没有跨越主值范围、纹理仍可见且运动模糊
可控，M-PME 仍可有效估计。阶段 4c 已用非正弦水平大运动叠加 0.42 px 微振动
验证了这一点。

真正危险的是“相位观测非线性”：弱纹理、方向/尺度不匹配、噪声、遮挡、亮度
变化或残差过大，会使局部相位梯度偏离稳定载波。本工程在原论文幅值置信度之外，
加入了 PNOF 启发的相位梯度非线性指标：计算相位梯度与邻域理想均值的相对偏差，
以其反比作为最小二乘权重，并按分布百分位自适应剔除低可靠约束。该实现是结合
公开方法描述的工程化版本，并非 PNOF 作者代码的逐式复刻。若真实视频仍出现失效，
优先路线是粗配准/绝对锚定去除大运动，再由 M-PME 测残差，而不是对错误时程做
低通平滑。
